# IBM Bob Usage Log

> **Why this file exists:** "Effective use of IBM Bob" is 25% of the score, and the README must document how Bob was used. Every PR adds one line here (see Definition of Done in [spec.md](spec.md)). This log becomes the source for the README's "How we used IBM Bob" section and the demo video.

Format: `what Bob did · feature/PR`.

> **On attribution:** IBM Bob was the primary development tool, which is what the challenge
> requires. Most rows record Bob's work directly. Rows tagged **Bob + AI-assisted** are those where
> another AI assistant worked in parallel with Bob, including every entry whose merged commits show
> a co-author publicly on GitHub. Either way the team set the direction, reviewed the output, and
> ran the tests.
